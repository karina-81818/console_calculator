# 🧮 Калькулятор на Go

Простой консольный калькулятор, поддерживающий четыре базовых арифметических операции: сложение, вычитание, умножение и деление.

## 📋 Описание

Программа последовательно запрашивает у пользователя:
1. Левый операнд (число)
2. Оператор (+, -, *, /)
3. Правый операнд (число)

После ввода всех данных выводится результат вычисления.

## 🚀 Возможности

- ✅ Поддержка операций: `+` `-` `*` `/`
- ✅ Защита от некорректного ввода чисел (повторный запрос)
- ✅ Проверка корректности оператора
- ✅ Обработка деления на ноль
- ✅ Работа с числами с плавающей точкой

## 🛠 Требования

- Go версии 1.16 или выше
- Только стандартная библиотека (без внешних зависимостей)

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/yourusername/calculator.git
   cd calculator
   ```

2. **Запустите программу:**
   ```bash
   go run main.go
   ```

## 💻 Примеры работы

### Пример 1: Обычное вычисление
```

```

```

10

```

## 🔧 Функции

| Функция | Описание |
|---------|----------|
| `inputNumber(str string) float64` | Ввод числа с защитой от некорректного ввода |
| `inputOperator(str string) string` | Ввод оператора с проверкой допустимых значений |
| `calculate(left, right float64, op string) float64` | Выполнение арифметической операции |
